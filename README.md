### 🛡️ Featured Project: [Sentinela](https://github.com/avilano/sentinela)

**Sentinela** is my playground for AI-augmented quality engineering and risk-based testing:

* 🎯 **Smart Risk Engine:** Analyzes git diffs on PRs to run only relevant specs (`@smoke`, `@pay`, `@a11y`) instead of waiting on the entire test suite.
* 🤖 **AI Failure Triage:** When a test breaks, an autonomous triage reporter inspects DOM locators, network traces, and stack errors to categorize the root cause (`APP_BUG`, `SELECTOR_DRIFT`, or `FLAKY_RACE_CONDITION`).
* 💥 **Chaos Testing:** Includes built-in chaos scenarios (like mocking a Stripe 500 payment failure) so you can watch the AI triage agent catch and diagnose issues in real-time.
* ⚡ **Stack:** Playwright, TypeScript, Docker, Stripe Webhooks, axe-core (WCAG 2.1 AA), and GitHub Actions.

👉 **[Check out the code & try the chaos demos →](https://github.com/avilano/sentinela)**
